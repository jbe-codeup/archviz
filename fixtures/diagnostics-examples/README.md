# Diagnostics examples

Importable diagrams that each demonstrate one of the validator diagnostics.
In Studio, click **Import** and pick a file — it opens as its own diagram.

| File | Shows |
|---|---|
| `role-trust-mismatch.archviz.json` | warning `role-trust-mismatch` — Execution Role trusts ec2, not ecs-tasks |
| `missing-workload-role.archviz.json` | error `missing-workload-role` (+ Lambda's `missing-required-connection`) — writes-to SQS with no IAM role |
| `ecs-deploy-checks.archviz.json` | warning `ecs-secrets-need-exec-role` + info `ecs-image-fallback` |
| `lb-single-az.archviz.json` | warning `lb-needs-two-azs` (ALB) + info `lb-single-az` (NLB) |
| `diagnostics-showcase.archviz.json` | all of the above in one canvas — errors, warnings and infos together |

Generated by `node scripts/write-diagnostics-examples.mjs`, which refuses to
write a file whose diagnostics drift from the table above; the same contract
is locked in CI by `packages/codegen/src/diagnostics-examples.test.ts`.
